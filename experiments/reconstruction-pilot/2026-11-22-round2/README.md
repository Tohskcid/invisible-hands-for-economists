第一篇兩組都能解釋最適選擇如何限制最適值的局部變動。一般組進一步推導策略集合上的單側導數。清單組主要處理各最適策略具有相同斜率的情況，因此雖然提到同一個應用，涵蓋的命題較窄。兩組都沒有完整處理任意選擇集合上，以鄰近最適選擇刻畫方向導數的結果。六個應用領域已由題包界定，這項實驗無法測量作者獨立選到哪些應用。[期刊原文](https://doi.org/10.1111/1468-0262.00296) · [一般組逐項對照](q001/submissions/X/fidelity.json) · [清單組逐項對照](q001/submissions/Y/fidelity.json)

第二篇兩組都區分了可達的改配路徑、可能循環的順序，以及隨機選擇下幾乎必然到達穩定配對的結論。兩組都指出，若有人對配對與單身無差異，從全員單身出發能到達的結果還需要額外條件。兩組都漏掉了原文與延遲接受程序、提案方最優結果、核心與策略性申報的部分連結。[期刊原文](https://doi.org/10.2307/2938326) · [一般組逐項對照](q002/submissions/Y/fidelity.json) · [清單組逐項對照](q002/submissions/X/fidelity.json)

兩題均由評稿模型先讀匿名稿並鎖定獨立品質分數，之後另開工作階段，用原文、附錄及封存規則逐項比對。各投稿目錄保留原稿、PDF、作者收據、兩階段評分與依據。兩篇選樣、每組一次，以及評稿判斷的不確定性，都限制這些分數的解釋。題目也容許不同且正確的論證。

## 專案變更

- **一般寫作是預設。** 這兩次比較沒有支持強制採用完整性清單。新流程保留清單作為可重測的選項。檢查研究品質與還原原文的評分各自留存。
- **題包審查在作者接手之前。** 公開的每項條件都有私下的原文頁碼和收錄理由。獨立審查者檢查實際交付的每個檔案。封存與匯出都驗證檔案指紋，解答、原文和書目識別資料留在策展工作區。
- **失分決定修正位置。** 題目缺必要條件時，另建版本並重新審查。原資料缺失時，保留該項的分母及缺口。若原文僅是多種合理做法之一，記錄替代做法及其適用範圍。作者推導錯誤才進入方法與論證的改進測試。

由已核實的原文執行讀稿、封存、寫稿與比對，可使用[操作說明](../../../references/benchmark_curation.md)。全庫的來源狀態及其他原文的處理情形另記，書目總數不能當作讀完的論文數。

風險趨避校準題的審查還揭露另一種洩漏。一份草稿在「交付要求」直接指定了效用界限的方向，雖然研究問題本身沒有給出該結論。讀稿指令已改為分別檢查研究問題、必要條件與交付要求。第三版移除方向提示後，審查確認公開題包未直接透露解答，但原文數值校準的若干索引與取整選擇仍無法唯一辨識。該版保留擱置決定、未發給作者。這是原文可讀而整篇仍無法可靠封題的一例。[Rabin 期刊原文](https://doi.org/10.1111/1468-0262.00158)

## 補足題意後，作者能多還原什麼？

根據第二篇的兩份初稿，新版題包增列一項制度比較，請作者考察分散調整、集中分配、集體偏離及偏好申報。審查者用期刊原文確認這些問題確實屬於論文範圍。題包沒有指定分配演算法及結論。原有的八項評分、權重、寫作指令及時間上限均沿用。新版通過審查並封存後，由一個新的無工具作者工作階段寫稿。[修正前固定的比較設計](scope-revision-design.json) · [新版研究問題與條件](q0140/public-task.json)

新版的一般組從 **13/16 提高到 14/16**，獨立品質維持 **8/8**。唯一變動的是制度比較，由 0/2 提高到 1/2。作者證明延遲接受機制的提案方最優性，也說明了穩定配對與核心的關係。它證明該機制的終點可達，但沒有證明分散市場的一連串改配能實現機制本身。新版還討論了偏好申報的誘因，仍漏掉原文的醫療配對背景及策略均衡與真實偏好穩定性之間的連結。這是一次依照舊稿失分所做的同題重測，且新作者自述熟悉配對理論。跨論文的改善幅度仍待獨立樣本檢驗。[新版論文](q0140/submissions/standard/manuscript.pdf) · [原版逐項分數](q002/submissions/Y/fidelity.json) · [新版逐項分數](q0140/submissions/standard/fidelity.json)
