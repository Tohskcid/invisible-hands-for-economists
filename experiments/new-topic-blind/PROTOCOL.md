# 已發表論文重建測試的時間規則

在選定目標、封存評分表、分派作者代理**之前**，記錄並以出版社／公開稿庫頁面核實：

- `first_journal_public_at`：目標首次期刊公開日，優先採線上發表日，不用後來的卷期年份。
- `first_target_public_at`：可核實的最早目標版本公開日；若另找到更早版本，立即重訂此日期並標記已開始的盲測受污染。
- 兩個日期的來源網址、存取日與原始頁面／擷取證據。

歷史原創性只和期刊首次公開日**之前**的外部研究逐項比較，並排除目標自身的預印本、工作論文、接受稿與期刊版。搜尋可以在今天執行，但每篇先行研究要用其首次公開日判定資格；日期不確定或剛好同日的作品不得自動算作「更早」。先用 `scripts/check_historical_prior_art.py` 分類時間資格，再由獨立審稿讀全文比較命題、模型與證明。日期分類不會給原創性分數。

「發表當時有哪些其他研究」與「誰最早提出某個結果」也不同：若目標預印本早於某篇競爭研究，該競爭研究雖可納入期刊發表時的背景比較，不能只憑較早的**期刊日期**宣稱它搶先目標。優先權須另比對各版本真正公開的時間和具體命題。

嚴格作者盲測只能提供在目標最早公開版本**之前**已可取得的材料；目標任何版本、其摘要及引用答案的後續文獻都要隔離。介於兩個截止日間的外部研究可由揭盲後的歷史新意審稿員使用，不能交給作者。封稿後分別報告三個指標：**內容重建分數**、**發表當時的歷史新意評估**、**今天作為新投稿的重複風險**。任何一項不能替代另外兩項。

作者來源清單在時間線中標記 `author_material: true`，交給作者前執行 `python3 scripts/check_historical_prior_art.py <timeline.json> --require-author-safe`；任何來源缺少截止日前公開證據就不得交付。此檢查只驗證清單與日期，無法阻止共享檔案系統或模型自身知識帶來的洩漏；另需保存實際來源交接、搜尋日誌及污染紀錄。

若要聲稱「限時盲測」，目標全文、身分與評分表須在作者啟動**前**封存，公開封存檔及題目雜湊；作者及其文獻／模型代理須用沒有策展內容的獨立上下文。作者最後稿件、PDF 與來源交接的雜湊須在時限內鎖定，且必須在揭盲前完成。遲鎖只能證明檔案最後寫入時間，不能補成準時封存。搜尋結果片段也可能洩露目標名稱；發生時立即停用該搜尋交接、記錄曝光，改由未接觸結果的代理使用已核實日期的安全來源。共用檔案系統上的指令隔離仍須明確標示為**程序隔離**，不能聲稱技術上無洩漏。

封稿後讓未看目標的審稿代理先做論證／寫作品質審查，再由可看封存評分表的代理做逐項內容重建評分。修訂可以繼續，但每輪必須保留原稿、時間、回饋來源及新分數；揭盲後的修訂不得改寫 one-shot 成績。

本 repo 的 b03 是在此協議補寫前執行；其事後修正及不合格的時間隔離見 [b03 補充協議](2026-10-17/b03/evaluation/historical-novelty-addendum.md)。
