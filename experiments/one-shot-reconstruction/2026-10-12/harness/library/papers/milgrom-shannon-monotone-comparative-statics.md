# Monotone comparative statics under order conditions

## Problem

- show optimal choices move monotonically with a parameter
- avoid differentiability and first-order-condition arguments

## Assumptions

- ordered choice and parameter sets
- appropriate lattice structure
- quasisupermodularity and a single-crossing condition in the relevant theorem

## Conclusion

Under the paper's order conditions, the optimizer correspondence is monotone in the relevant set order, yielding monotone extremal selections where defined.

## Method

lattice and order-theoretic comparative statics

## Proof strategy

- compare optimizers at ordered parameter values
- use single crossing and quasisupermodularity to order extremal selections

## Failure conditions

- single crossing alone may not order a multidimensional choice set
- a missing lattice or feasibility-set condition can break monotonicity

## Scope note

Match the exact theorem variant to whether the feasible set also changes with the parameter.
